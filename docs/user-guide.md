# IoT 数据中台 — 用户手册

---

## 概览

数据中台管理控制台提供以下功能模块：

| 模块 | 说明 |
|------|------|
| 概览（Dashboard） | 设备统计、实时数据概览 |
| 设备管理 | 设备注册、查询、删除、状态监控 |
| 规则引擎 | 数据处理规则的创建、编辑、启用/禁用 |
| 物模型 | 设备物模型定义（属性、命令、事件） |
| 告警中心 | Webhook 配置、告警日志查看 |
| 域管理 | 业务域创建、成员管理与角色分配 |

---

## 1. 概览（Dashboard）

**路径：** `/dashboard`

概览页面展示系统整体运行状态：

- **设备总数** — 系统中注册的全部设备数量
- **在线设备** — 当前处于在线状态的设备数量
- **今日上报** — 今日收到的设备数据上报总条数
- **活跃告警** — 当前未处理的告警数量

下方表格展示最近的告警事件，包含时间、设备、消息内容和告警级别。

## 2. 设备管理

**路径：** `/devices`

### 查看设备列表

进入设备管理页面后，设备列表自动加载。表格显示以下信息：

| 列 | 说明 |
|------|------|
| 设备ID | 设备唯一标识 |
| 名称 | 设备名称 |
| 类型 | 设备类型（如 sensor） |
| 协议 | 通信协议（mqtt / tcp / modbus） |
| 业务域 | 所属业务域 |
| 状态 | 在线（绿色标签）/ 离线（灰色标签） |

### 添加设备

1. 点击页面右上角 **"添加设备"** 按钮
2. 填写设备信息：
   - **设备ID**（必填）：唯一标识，如 `sensor-001`
   - **名称**（必填）：设备名称，如 `车间A温度传感器`
   - **设备类型**（必填）：如 sensor、actuator、gateway
   - **协议**（必填）：mqtt、tcp 或 modbus
   - **业务域**（必填）：选择设备所属域
   - 地区、模型ID、固件版本为可选项
3. 点击确定

> 系统会自动为设备生成一个 Token（64 位），用于设备认证。请妥善保存该 Token。

### 删除设备

1. 在设备列表中找到目标设备
2. 点击该行右侧的 **"删除"** 按钮
3. 在确认弹窗中点击确定

## 3. 域管理

**路径：** `/domains`

业务域用于多租户隔离。不同域的设备、模型、规则、告警相互隔离。

### 创建域

1. 点击 **"添加域"** 按钮
2. 填写：
   - **域ID**（必填）：如 `factory-a`
   - **名称**（必填）：如 `工厂A`
   - 描述：补充说明
3. 点击确定

### 管理域成员

1. 在域列表中点击某一行，下方展开该域的成员管理区域
2. **添加成员**：点击"添加成员"按钮，输入用户ID并选择角色
3. **移除成员**：点击成员行右侧的"移除"按钮

**角色说明：**

| 角色 | 权限 |
|------|------|
| super_admin | 超级管理员，可管理所有资源 |
| admin | 管理员，可管理域内所有资源 |
| operator | 操作员，可操作设备和查看数据 |
| viewer | 观察者，仅可查看数据 |

### 删除域

点击域行右侧的"删除"按钮即可。注意：删除域会同时删除其下所有成员关系。

## 4. 物模型

**路径：** `/models`

物模型定义了设备的数据结构：属性（Property）、命令（Command）、事件（Event）。

### 查看模型列表

1. 使用顶部的 **域过滤器** 选择业务域，查看该域下的所有模型
2. 表格显示：模型ID、名称、业务域、属性数、命令数、事件数

### 创建物模型

1. 点击 **"添加模型"** 按钮
2. 填写基本信息：
   - **模型ID**（必填）：如 `temp-sensor-v1`
   - **名称**（必填）：如 `温度传感器模型`
   - **业务域**（必填）：所属域
3. 添加属性定义（可添加多个）：
   - **属性ID**：如 `temperature`
   - **名称**：如 `温度`
   - **类型**：float / int / string / bool / enum
   - **单位**：如 °C、%、Pa
4. 点击 **"+ 添加属性"** 继续添加更多属性
5. 点击确定保存

### 删除模型

点击模型行右侧的"删除"按钮即可。

## 5. 规则引擎

**路径：** `/rules`

规则引擎用于处理设备上报的数据，支持过滤、转换、条件判断、聚合和脚本处理。

### 查看规则列表

1. 使用域过滤器筛选特定域的规则
2. 表格显示：规则ID、名称、Topic、业务域、节点数、启用状态
3. **启用/禁用**：点击状态列的开关即可实时切换

### 创建规则

1. 点击 **"添加规则"** 按钮
2. 填写基本信息：
   - **名称**（必填）：如 `高温告警规则`
   - **业务域**（必填）：所属域
   - **Topic**：NATS Subject，如 `sensors.temperature`
   - **启用**：是否创建后立即启用
3. 配置节点链（按顺序执行）：
   - 点击 **"+ 添加节点"** 添加处理节点
   - 选择节点类型并配置参数：

**filter（过滤）：** 按字段匹配筛选消息
- `field`：匹配字段（如 topic）
- `operator`：匹配方式（eq 等于 / contains 包含 / prefix 前缀匹配）
- `value`：匹配值

**condition（条件）：** 基于表达式判断
- `expression`：条件表达式

**aggregate（聚合）：** 滑动窗口聚合
- `window_size`：窗口大小
- `function`：聚合函数（avg / sum / min / max / count）

**script（脚本）：** 自定义 JavaScript 处理逻辑
- `script`：JavaScript 代码，可使用 `device_id`、`data` 等变量

4. 点击确定保存

### 删除规则

点击规则行右侧的"删除"按钮即可。

## 6. 告警中心

**路径：** `/alerts`

告警中心管理 Webhook 通知配置和告警日志。

### Webhook 配置

点击 **"Webhook 配置"** 标签页：

| 列 | 说明 |
|------|------|
| ID | Webhook 唯一标识 |
| 名称 | Webhook 名称 |
| URL | 接收告警的 URL |
| 方法 | HTTP 请求方法 |
| 业务域 | 所属域 |

#### 添加 Webhook

1. 点击 **"添加 Webhook"** 按钮
2. 填写：
   - **名称**（必填）：如 `钉钉机器人告警`
   - **业务域**（必填）：所属域
   - **URL**（必填）：告警接收地址，如 `https://oapi.dingtalk.com/robot/send`
   - **请求方法**：POST（默认）或 GET
   - **告警级别**：勾选要接收的级别（严重 / 警告 / 信息）
3. 点击确定保存

#### 测试 Webhook

1. 在 Webhook 列表中找到目标
2. 点击 **"测试"** 按钮
3. 系统发送一条测试告警到该 Webhook
4. 显示发送结果（成功/失败）

#### 删除 Webhook

点击"删除"按钮即可。

### 告警日志

点击 **"告警日志"** 标签页查看历史告警发送记录：

| 列 | 说明 |
|------|------|
| 告警ID | 告警事件标识 |
| Webhook | 发送目标 |
| 状态 | sent（成功）/ failed（失败）/ rate_limited（限流） |
| 响应 | Webhook 返回的响应内容 |
| 时间 | 发送时间 |

## 常见问题

### Q: 设备 Token 在哪里查看？

在设备管理页面，创建设备时系统会自动生成 Token。Token 在 API 响应的 `token` 字段中返回。建议创建设备后立即保存 Token。

### Q: 如何修改设备信息？

通过 API 的 `PUT /api/v1/devices/:id` 端点修改。前端暂未提供编辑对话框，后续版本会补充。

### Q: 规则引擎的脚本节点如何编写？

脚本使用 JavaScript 语法，通过 [Goja](https://github.com/dop251/goja) 引擎执行。可用变量：
- `device_id` — 设备ID
- `domain_id` — 域ID
- `timestamp` — 时间戳
- `data` — 上报数据

示例：
```javascript
if (data.temperature > 80) {
  log("高温告警: " + data.temperature);
}
```

### Q: 告警被限流了怎么办？

默认限制每分钟 10 条。可在 Webhook 配置中调整 `max_per_minute` 参数。

### Q: 数据存储在哪里？

- 设备信息、域、物模型、规则、Webhook 配置 → SQLite（开发）/ MySQL/PostgreSQL（生产）
- 设备上报的时序数据 → TDengine
- 设备在线状态 → Redis
